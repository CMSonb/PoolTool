Process: 
1.	Upload of the data in the top most box. 
2.	Processing of the data: semantic similarity analysis based on a provided vocabulary list (from us), matching possible candidates from the new data to this list. Example: Foto, Fotos, Fotographie  Fotografie. 
3.	After this, candidates for matching are presented in a box on the left, listing the variants possibly linked to the vocabulary list match. Print the first three ids of possible matches, and include in brackets the number of all matches, allowing the expansion of all ids in an expandable drop down menu. A second box on the right of this box will be the goal-word from the vocabulary list. 
4.	By clicking the word, you select it, and are able to select multiple. Below is a “go” button, that when pressed, changes those selected words, but keeps the unselected as they are. It then moves to the next word on the vocab list. On the left next to the left box there is a vertical progress bar for each word of the vocab list, highlighted on which word we are and filling a circle for those already checked or processed.
5.	We go through each vocab word and when we have pressed the last go, we have a field with “Save changes and export” which when pressed will download the new changed data file as json. In addition, provide a log file of the changes made, including the ids and the respective changes.
